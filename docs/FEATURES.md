- `[x]` **Background Filter Auto-Update Engine (WorkManager)**: Daemon-free background synchronization using Android OS `JobScheduler` via `FilterUpdateWorker` (supporting 6h, 12h, 24h, 3d, 7d intervals, mobile data and Wi-Fi networks via `NetworkType.CONNECTED`, and battery protection), with race-condition immunity against cold process startups and atomic `.tmp` replacement for `onyx_filters.bin` binary cache.
- `[x]` **Dual-Tier Adblocking & CNAME Uncloaking**: Standard vs Aggressive shields with instant dynamic reversion at document start, plus dual-pass CNAME uncloaking matching both original alias and uncloaked destination.

## 2. Multi-Profile & Incognito Browsing

- `[x]` **Chromium Multi-Profile Partitioning**: True physical session isolation using `ProfileStore.getOrCreateProfile("incognito")` and `WebViewCompat.setProfile()`.
- `[x]` **Ephemeral Storage & Automated Purge**: Closing all incognito tabs instantly destroys cookies, localStorage, IndexedDB, and partition caches.
- `[x]` **Biometric Incognito Protection**: Protect private tabs behind fingerprint or face authentication using AndroidX `BiometricPrompt`.
- `[x]` **Universal OAuth & Auth Grace Period**: Maintains strict cookie isolation while granting smart grace periods during authentication flows (Google, Apple, Meta, GitHub, Microsoft).
- `[x]` **Anti-Bot Window Hash (`wh`) Reflection Masking**: Hides Android Java bridges and internal properties from prototype reflection, matching authentic Chrome telemetry.
- `[x]` **WebAuthn Passkeys, Credential Manager & Universal Password Managers**: Full FIDO2 / WebAuthn Level 3 passkey creation and sign-in (`PublicKeyCredential`, CBOR `attestationObject` DER SPKI extraction, `rpId` suffix verification, conditional mediation protection) plus canonical `clientDataJSON` injection matching authenticator `clientDataHash` signatures to guarantee cryptographic verification on relying parties (e.g. GitHub, Google, Microsoft), W3C `PasswordCredential` (`get`/`store`), and Android `AutofillManager` support across third-party password managers (Bitwarden, Proton Pass, 1Password, KeePassDX, KeePass2Android, Dashlane, Enpass, NordPass, Samsung Pass) via `CREDENTIAL_MANAGER_SET_ORIGIN` and `autofillServiceComponentName` detection. Authentic Chrome `userAgentData` masking removes embedded WebView signatures for Google OAuth flows.
- `[x]` **Context-Aware Incognito Navigation**: Long-pressing a link while browsing in incognito mode opens "Open in new tab" inside a new incognito tab while omitting the redundant "Open in incognito tab" option, matching standard privacy browser ergonomics.
- `[x]` **Chrome-Grade Incognito Keyboard & Clipboard Isolation**: Dynamically propagates Android's `EditorInfo.IME_FLAG_NO_PERSONALIZED_LEARNING` across both the Omnibox and in-page WebView input connections (`onCreateInputConnection`) during private sessions. This instructs virtual keyboards (such as Gboard and Samsung Keyboard) to enter native Incognito mode, halting predictive learning and suppressing clipboard history logging (preventing private snippets from persisting in keyboard history trays) while preserving standard system-level copy/paste functionality without artificial placeholder masking. Suppresses in-app omnibox clipboard suggestions during private sessions.

## 3. Media, Audio & Video Playback

- `[x]` **Background Audio & Video Playback**: Full background playback with Brave & Firefox Page Visibility interception, player touch intent tracking, non-user pause suppression across tab switches & screen lock, Wi-Fi & WakeLock sleep prevention, W3C `setPositionState` real-time position tracking, in-place `MediaMetadata` prototype mutation synchronization, pixel-area highest-resolution artwork selection, baseURI relative URL resolution, multi-source metadata fallbacks (OpenGraph, Twitter card, Apple touch icons), inline Base64 data-URI decoding, and YouTube inactivity (`_lact`) keep-alive.
- `[x]` **Picture-in-Picture (PiP) Architecture**: Stylesheet-only single-element `[data-onyx-pip-video]` isolation across Light DOM, Shadow DOM, and cross-origin player `<iframe>`s without clobbering inline styles, viewport-normalized `sourceRectHint` cropping, clamped `[0.5, 2.0]` aspect ratio updates on live `<video>` resize, active-tab video gating (`isActiveTabVideoPlaying`), deterministic expand-vs-close ('X') lifecycle resolution (`pendingPipCloseCheck`), preserved fullscreen PiP/Close overlay controls with auto-hide, Android 12+ `setAutoEnterEnabled` + Android 8-11 `onUserLeaveHint` transitions, and live RemoteAction synchronization.
- `[x]` **Android Audio Focus Management**: Delegated to the WebView media session (no competing service focus request), noisy-disconnect pause, and no auto-resume during calls.
- `[x]` **Lockscreen Playlist Autoplay Grace Gap**: 2000ms debounce across `onMediaEnded` track-advance transitions to prevent dropping foreground services or lockscreen media controls during sequential playlist autoplay.
- `[x]` **Theme Recreation Shielding**: Defers `recreate()` in `onResume` and `onConfigurationChanged` during active PiP mode (`maybeDeferNightModeRecreate`), preventing PiP window destruction on system night mode changes.
- `[x]` **Battery & CPU Tab Governor**: Inactive background tabs are suspended via `onPause()` while keeping JavaScript timers alive strictly on the active media tab (`mediaTabWv.resumeTimers()`).
- `[x]` **Foreground Media Service**: `MediaPlaybackService` with lockscreen notification controls, Wi-Fi lock, progress tracking, and MediaSession sync. Progress-triggered notification rebuilds are throttled (5 s service-side, 3 s bridge-side) to prevent main-thread binder IPC jank during active playback. Notification uses `CATEGORY_TRANSPORT`, `setSilent(true)`, and `PRIORITY_DEFAULT` for correct MediaStyle display across all OEMs.
- `[x]` **Universal Transparent Video Poster**: Replaces default gray video box and play icon with a transparent poster for seamless video loading.
- `[x]` **Audio Becoming Noisy Broadcast Receiver**: Automatically pauses playback when headphones are disconnected or Bluetooth disconnects.
- `[x]` **Stream Detector**: Automatically sniffs downloadable audio/video streams from websites.

## 4. Tabs & Navigation Architecture

- `[x]` **Visual Tab Switcher**: High-performance Jetpack Compose grid preview cards with live snapshots, domain labels, snapshot revision caching for instant thumbnail updates, dark/light/AMOLED theme contrast matching, biometric incognito access gates, dynamic settings-driven accent color synchronization (eliminating hardcoded accent fallbacks across FAB, cards, undo toasts, and segmented indicators), and unified bottom action bar featuring solid 44dp squircles (`surfaceVariant` background) with `ic_delete` (clear browsing data/history), 48dp circular accent-tinted `ic_add` FAB, and `ic_tab_close` (close all tabs).
- `[x]` **Tab Context Menu & Quick Tab Actions**: Long-pressing any tab card in the switcher opens a Material 3 sheet to Close tab, Close other tabs, Duplicate tab, Copy link, or Share link. Long-pressing the toolbar tab switcher button displays a fast popup menu to quickly spawn tabs or close the current tab. Browser main menu includes a dedicated "Close Tab" action for active pages.
- `[x]` **Safe Tab Dismissal & WebView Synchronization**: Overridden dismissal lifecycle ensures closing active tabs in the switcher and dismissing via system back gestures cleanly synchronizes `MainActivity` to the current active tab or creates a fresh default tab, preventing ghost/destroyed WebView pointer leaks.
- `[x]` **Swipe-to-Dismiss & Batch Undo**: Full bidirectional swipe-to-dismiss gestures (swiping left or right) on tab cards in the Jetpack Compose tab switcher (`TabSwitcherBottomSheet`), featuring dynamic hardware-layer alpha fade, 35% drag distance threshold and 800px/s fling velocity detection, smooth slide-out exit animation, spring snap-back physics on cancel, and single/batch undo notifications.
- `[x]` **Zero Unwanted Tab Auto-Creation**: Closing the last tab cleanly transitions to the home screen without forcing an empty placeholder tab.
- `[x]` **Non-Destructive Navigation**: Hardware back button at history root minimizes the browser rather than terminating processes or losing tab state.
- `[x]` **Safe Popup Window & External Link Promotion**: Links opening in new windows (`window.open`, `target="_blank"`, such as Facebook post links or external references) seamlessly promote to new active tabs with target URL synchronization, preventing empty-URL homepage regressions and detaching.
- `[x]` **Chromium Network Error Pages & Protocol Resilience**: Full closed-loop synthetic error page modeling (`WebErrorHandler`) mapping all native Chromium network error codes, including `net::ERR_INVALID_RESPONSE`, `net::ERR_INVALID_CHUNKED_ENCODING`, `net::ERR_NAME_NOT_RESOLVED`, `net::ERR_INTERNET_DISCONNECTED`, and SSL validation errors with tailored diagnostic checklists, Reload CTA, and Wayback Machine cache inspection.
- `[x]` **Adjacent Tab Selection on Tab Dismissal**: Closing an active tab automatically shifts focus to the adjacent neighbor tab rather than jumping across the tab bar to the end of the list.
- `[x]` **Accurate Window Close Targeting**: Scripted `window.close()` invocations strictly target the specific originating tab rather than arbitrarily closing whatever tab the user is actively viewing.
- `[x]` **Transient Popup Cleanup**: Popups created solely to initiate downloads or launch external app schemes (WhatsApp, Telegram, Google Play) automatically retire upon handoff, preventing stranded blank tabs.
- `[x]` **Non-Destructive Tab Switching**: Switching between tabs preserves live DOM state, forms, and scroll position without reloading loaded pages.
- `[x]` **Tab Memory Optimization & RAM-Aware LRU WebView Pool Governor**: Background tabs suspend JavaScript timers via `onPause()` to conserve RAM and battery, while `TabCoordinator` enforces a strict RAM-aware LRU WebView pool (`maxLiveWebViews` 3–5 scaled by `ActivityManager.MemoryInfo`), hibernating inactive non-media tabs to disk or in-memory `incognitoStateBundles`.
- `[x]` **Safe-Mode Resource & Code Shrinking (R8 + isShrinkResources)**: Release builds combine full R8 code optimization with `isShrinkResources = true` safeguarded by `res/raw/keep.xml` (`tools:shrinkMode="safe"`), aggressively pruning unused third-party library assets while strictly preserving 100% of Onyx drawables, vector silhouettes, XML configurations, and native bridge interfaces without disrupting runtime functionality.
- `[x]` **Unidirectional Data Flow (UDF) ViewModels, Repository Layer & Modular Coordinators**: Reactive `StateFlow`-driven presentation architecture (`BrowserViewModel`, `HistoryViewModel`, `BookmarksViewModel`, `DownloadsViewModel`, `AppViewModelFactory`) backed by constructor-injected repositories (`HistoryRepository`, `BookmarkRepository`, `DownloadRepository`, `SitePermissionRepository`), domain preference stores (`AppearancePreferences`, `ShieldPreferences`, `MediaAndDownloadPreferences`, `SearchPreferences`), externalized JS assets via `AssetScriptLoader` (`passkey_webauthn_polyfill.js`, `media_playback_observer.js`, `adblock_procedural_engine.js`), Room KSP schema tracking (`room.schemaLocation`), Gradle Version Catalog (`gradle/libs.versions.toml`), CI unit test verification (`:core:common:test testReleaseUnitTest`), `AppContainer` DI, `:core:common` shared utilities, `ExternalNavigationHandler` scheme/intent routing, `MainActivity` UI delegates (`ToolbarLayoutController`, `BrowserMenuCoordinator`, `NavigationCoordinator`, `WebChromeCoordinator`, `HomeScreenController`, `FileChooserCoordinator`, `WebContextMenuCoordinator`, `SettingsNavigator`), and one-command developer bootstrap (`scripts/bootstrap_dev.sh`, `CONTRIBUTING.md`, `SECURITY.md`, `.editorconfig`, `.github/PULL_REQUEST_TEMPLATE.md`).
